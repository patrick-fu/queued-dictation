# queued-dictation

macOS 原生语音输入工具，首版规格见 [issue 22](https://github.com/patrick-fu/queued-dictation/issues/22)。当前实现包含录音、BYOK 转写与润色、连续片段 FIFO 调度、独立英语带教、加密历史与收藏，以及焦点交付守护；完整实机与发布包验收仍在进行。

## 构建与运行

需要 Apple Silicon、macOS 14 以上与 Swift 6 工具链。无需第三方依赖或模型服务凭据。

```sh
swift test
bash Scripts/build-app.sh debug
open "dist/Queued Dictation.app"
```

从 Dock 打开 App，主窗口侧栏统一提供历史记录、待交付队列、模型、英语带教、收藏和设置。`⌘,` 打开设置；关闭主窗口后快捷键仍可用，再次点击 Dock 图标可重新打开。当前不提供独立菜单栏状态入口。首次可以选择「稍后设置」。模型页保存共享服务的 Base URL／鉴权方式，转写角色另外引用服务与模型；密钥另存钥匙串，空白保留原密钥，删除密钥有独立操作。云端和自管本地端点都使用 multipart `/audio/transcriptions`，允许无鉴权本地服务。实际文件转写成功才证明所选角色能力；模型列表不作为能力证明。

新配置默认按一下 Fn 开始录音，再按一下结束；设置中可选择按住录音、松开结束，也可改为组合键。已有明确保存的录音方式会保留。录音时只显示 260×52 点的非激活小胶囊，左侧叉号取消当前片段，中间波形反映麦克风音量，右侧勾号结束录音。将光标放在目标输入框后使用快捷键；开始时记录可写目标、窗口、正文指纹和选区。失焦、手打、移光标、权限拒绝或监测不可靠时转手动。自动插入不操作剪贴板、不切回目标。历史中可复制、下载原文或打开非激活取用面板；写回不确定时只能检查目标并确认，复制不标记交付完成。麦克风拒绝或撤销时，历史和下载仍可使用。

转写仅发送本段 WAV 和所选模型 ID。缺配置保留音频；同次运行修复配置后只续发未发送片段。已发请求不因改配置重发，失败／超时须显式重试。默认整体截止 60 秒，可设置 5–600 秒，覆盖上传与完整有效响应；到期取消实际网络任务，旧尝试不能写回或覆盖重试。每段网络状态与录音状态独立，请求在途时可录下一段；主请求与带教并发默认各为 3，主交付保持录音顺序。

`bash Scripts/build-app.sh release` 生成 arm64 开发 App。脚本使用本地临时签名；Developer ID 签名、公证与正式发布包由发布票实施，开发包不代表正式安装包验收通过。

## 本地保护与额度

数据目录为 `~/Library/Application Support/QueuedDictation`。音频从第一块落盘开始使用 AES-GCM 加密；历史元数据也加密，独立数据密钥由系统钥匙串管理。录音过程中没有持久明文暂存。缺少密钥或数据损坏会提示错误并保留原文件，不能通过新建密钥自动修复。

默认单段 5 分钟、全本地数据 5 GiB。额度按逻辑字节与实际文件分配空间取较大者计入，加密收尾预留 1 MiB，真实磁盘另保留 64 MiB；触顶停止录音并保留已成功保存的有效音频。主动取消当前录音丢弃当前音频；录完后取消片段保留历史和下载。无音频不创建空条目。

历史读取和录音前按默认 30 天清理已完成或已取消条目；待处理片段不会因此被删除。转写原文及角色尝试／交付元数据与音频使用同一独立数据密钥加密。普通服务配置位于 `~/Library/Application Support/QueuedDictationSettings/services.json`，不含 API 密钥或口述正文；API 凭据使用独立钥匙串命名空间，修改它不影响已有历史解密。更新地址和密钥时用新的凭据引用原子提交配对，保存失败不会把新密钥交给旧地址；旧配置保持兼容。

从首次接网限制响应体为 1 MiB、有效原文为 256 KiB。派发前与保存结果前检查本地额度／真实磁盘余量，并预留 JSON 编码和原子保存空间。结果保存失败不会上屏或假称可下载，不自动重发。用户主动下载的 WAV／UTF-8 文本是普通文件，下载位置须在加密数据目录以外。重启后的在途请求显示结果未确认，必须显式重试；旧目标不能自动恢复。中断录音和完整队列恢复清单由后续票实施，现有 active 音频块仍为加密文件。

## 检查与接口

`swift test` 从 `RecordingApplication` 的录音操作入口检查历史、实际 WAV 解码、取消、额度、权限变化、密钥丢失和文件保护；转写检查通过真实 URLSession 与可控 URLProtocol 验证请求内容、动态密钥、整体截止、实际取消、迟到结果、异常和持久化失败，交付使用可控外部边界。所有音频和密钥均为合成／测试数据，不连接真实模型服务。CI 构建开发 App 并执行相同行为检查。

真实麦克风、BYOK 能力样本、localhost／IP／LAN 授权与 ATS、TCC 拒绝／撤销／恢复、TextEdit 焦点／编辑通知／撤销／富文本、macOS 14 实机、原生窗口布局和正式签名包需另行实机验收。自动化合成音频及交付替身不能替代这些证据。

后续模块接入约定见 [录音与历史接口](docs/implementation/recording.md)及[转写与交付接口](docs/implementation/transcription.md)。源代码采用 MIT 许可证。
