# 录音、润色与文本带教的垂直接线

本切片将 [#28 润色](https://github.com/patrick-fu/queued-dictation/issues/28) 和 [#32 文本带教](https://github.com/patrick-fu/queued-dictation/issues/32) 的既有客户端接入 `RecordingApplication`、加密历史和 AppKit 入口。两票的原生依赖与实机验收尚未完成，不能据此宣布整票关闭。父规格 [#22](https://github.com/patrick-fu/queued-dictation/issues/22) 继续约束后续切片。

## 真实处理链路

录音结束后保存真实结束时间 `recordingEndedAt`，录音开始时间 `recordedAt` 保持原样。PCM 音频继续逐块 AES-GCM 加密保存。ASR 的有效原文先写入既有 `entry.enc`；保存成功后，润色与带教都取同一份未经润色的原文。

转写与润色取得同一个 `MainRequestBudget` 的槽位，默认并发 3，现有 `ProcessingSettings` 提供 1–10 配置。排队等待不启动请求截止。实际派发才读最新服务、凭据、角色和完整提示词；先加密保存 `inFlight` 再启动 HTTP。带教只使用既有 `CoachWorkScheduler` 的独立池，默认并发 3，不占主槽位和主积压名额，也不等待润色完成。

关闭润色时原文成为候选。启用但缺服务、模型或凭据时保留原文并等待配置。已经发送的润色失败、格式失败或超时，保存该次失败后以原文作为当前候选；它仍遵守录音开始顺序的 FIFO 与原目标保护，带教继续运行。保存状态或结果失败则不自动交付、不出卡、不自动重新请求。

`VoiceHistoryEntry` 新增的 `polishedText: String?`、`polish: PolishRecord?`、`coach: CoachWorkUpdate?`、结束时间和续窗时间都进入同一份加密元数据。缺失字段可以解码成 nil，旧条目不会出现虚构的润色或带教产物。网络错误只记录稳定失败原因，不保存服务商错误正文或 API 密钥。

## 取用、重润色与失效

`currentText`、`copyCurrentText`、`insertCurrentTextAtCurrentCursor` 取当前已保存的润色文本，缺润色产物时取原文。`rawTranscription`、`copyRawTranscription`、`insertRawTranscriptionAtCurrentCursor` 继续明确取原文。队列和默认手动面板使用当前候选；原文与润色文本可分别主动下载。复制不会放行队头；手动插入、确认外部已经粘贴、跳过或取消仍通过原 FIFO 规则放行。

`repolish` 为已有原文创建新的尝试，竞争同一个主槽位，实际发送前仍读最新配置。它只更新历史供手动取用，既不重复 ASR 或带教，也不重新写入已经交付的文档。

片段取消、删除、保留期清理、普通停止和退出准备都会同步撤销相关尝试身份、请求槽位与自动交付资格，并取消实际请求。删除前先撤销带教注册，迟到结果不能重建条目。主流程完成或跳过不取消独立带教。单张卡移走仅删除显示；关闭统一带教开关清空整窗并取消旧工作，关闭时已经有效的结果只进历史，重新开启只接纳之后的新片段。

同步观察者和持久化检查可以触发取消、删除或停止；返回后重新核验当前尝试与停止世代。普通停止返回后允许新显式工作，栈内旧观察者不能重新挂入旧段。`prepareForTermination` 永久拒绝新的录音、重润色和两种手动插入入口。普通停止保留旧队头：新段可以处理，但必须等待旧头显式处置后交付。

## 自动发送时间窗

主请求与带教门禁直接读取既有 `ResourceSettings`，使用 `ResourceConfiguration.isAutomaticSendingExpired`；默认 24 小时，范围 1–168 小时。起点是实际录音结束时间，主动续窗使用加密保存的 `automaticSendingStartedAt`，旧格式只能保守使用已有录音时间。恰好到边界仍有效，超过边界暂停尚未发送的工作。请求一旦发送，其完整截止继续由各客户端约束。

暂停后调大时间窗或补齐模型配置不会静默续发。队列与历史的“恢复未发工作”明确续窗，保持录音时间和 FIFO。主流程已经完成的片段仍可单独恢复尚未发出的带教。外部 `canDispatch` 是附加门禁，不能绕过默认时间窗或角色身份校验。

本次只接入资源模块的时间窗来源。动态录音额度、离线恢复、Retry-After、重启恢复清单、ZIP、收藏和音频带教仍由后续切片集成。

## App 入口

菜单栏常驻同一个“英语带教和卡片浮窗”开关，录音胶囊和设置窗复用它；整窗关闭沿用同一设置。润色设置复用共享服务 CRUD，保存后同时通知尚未派发的转写、润色和带教重新检查最新配置。带教设置链接到同一个共享服务编辑入口。缺配置或失败原因保持可见，模型回调只通过统一 `onChange` 刷新现有卡片窗。

历史可查看已保存原文、润色和文本带教，单卡移走后仍能找回反馈。文本模式继续显示无音频、不评流利度，并且没有数字评分。原有四角、滚动、到达顺序和非激活卡片窗保持原实现。本切片的 App 仍接 TextEdit 交付适配器；当前输入所在屏幕尚待 #27 适配器集成，卡片窗的默认屏幕回退不能作为跨屏实机验收证据。
