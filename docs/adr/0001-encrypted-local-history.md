# 本地语音数据默认加密保存

首版会在本机保存录音、语音历史和带教收藏，用户选择对这些持久化内容默认加密。应用使用系统钥匙串管理独立的本地数据加密密钥，用户无需另设密码；模型服务的 API 密钥也存入钥匙串，但不作为历史数据的加密密钥，避免更换服务凭据影响已有数据的可读性。待处理队列中的落盘音频同样属于这个保护范围，主动导出的音频、文本和 ZIP 则为普通文件。

这项选择增加了数据迁移和密钥恢复的要求：仅复制数据目录不保证能在另一台设备上解密。实现时必须明确处理钥匙串不可用、密钥丢失及临时文件清理，不能因无法解密而静默覆盖或清空原数据；首版尚未承诺迁移功能。产品决议见[确定 BYOK 数据与隐私边界](https://github.com/patrick-fu/queued-dictation/issues/7)。
